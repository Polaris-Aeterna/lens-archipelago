## 这是什么

<b>《透镜群岛》是一场在浏览器里进行的互动知识旅程。</b>它改编自一份关于语言、逻辑、价值与物理的精读笔记《语言是一面透镜》：笔记有十一章，群岛就有十一面透镜。

这里的知识不是读出来的，是**用手弄懂的**。

<table>
<tr>
<td width="50%" valign="top">

- 用英语、俄语、古汉语的“刀”，亲手**切开同一道彩虹**
- 去开一把**被数学证明打不开的锁**
- 当一回**麦克斯韦妖**，然后为遗忘付出热量

</td>
<td width="50%" valign="top">

- 把飞船推向光速，看着<b>“现在”倾斜</b>
- 凿掉一切<b>“不是它”</b>的部分，让答案自己显形
- 判断引路人的八条证词：**你信几句？**

</td>

## 本地运行

不需要构建，也没有任何依赖。克隆仓库后，在仓库目录里启动任意一个静态服务器：

```bash
git clone https://github.com/Polaris-Aeterna/lens-archipelago.git
cd lens-archipelago
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。`#map` 是群岛地图，`#codex` 是光谱图鉴，`#l01` 到 `#l11` 直接进入对应的透镜。

```text
lens-archipelago/
├── index.html      页面外壳与全部样式
├── engine.js       引擎：开场、群岛地图、知识之桥、图鉴、镜灵、声音、关卡 API
├── finale.js       终章：白光汇合、纽拉特之船、带走的问题
├── levels/         十一面透镜，每面一个文件（l01.js … l11.js）
└── media/          宣传片、截图与 README 素材
```
